## About Cryptic PC

Cryptic PC provides a local Windows desktop environment for running Roblox Lua scripts. Its interface is intentionally lightweight, while the included script hub gives users a central place to browse and launch scripts on 64-bit Windows 10 and Windows 11 installations.

The project also includes public API support and an auto-update release approach for keeping up with current builds. Its open source organization is designed to remain easy to review, navigate, and extend without relying on an oversized interface.
